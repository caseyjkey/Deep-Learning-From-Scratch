4. a. A is an m x n matrix
r is the rank of matrix A (linearly independent rows or columns)
theta_i is the i-th singular value
u_i is the i-th left singular vector from orthonormal basis of R^m
v^T_i is the i-th right singular vector from orthonormal basis of R^n

We can reach the equation in question by matrix multiplication.
U * D scales each column in U by theta_i (theta_1*u_1, theta_2*u_2, ..., theta_r*u_r)
Multipling that by V^T gives us the final result.
theta_1*u_1*v^T_1 + theta_2*u_2*v^T_2 + ... + theta_r*u_r*v^T_r

b. We can achieve this definition by following the previous summation
To isolate u_i, we can multiply both sides by v_i
A * v_i = summation from j=1 to r of theta_j * u_j * v^T_j * v_i
Since v is an orthonormal basis, v^T_j * v_i = 1 if j = i, and 0 otherwise
Therefore, A * v_i = theta_i * u_i
Then we divide both sides by theta_i to get u_i = (1/theta_i) * A * v_i

c. From b we can see that theta_i * u_i = A * v_i
Using that in the summation, we have A_k = summation from i=1 to k of (A*v_i)*v^T_i
representing the projection of rows of A onto the first k right singular vectors.

d. To show that A_k minimizes ||A - B||_F^2 as B for all B of rank k, we can use the fact 
that the closest point in a subspace to a matrix is its orthogonal projection onto that subspace.
The projection of A onto V_k, the best-fit subspace which minimizes error among all subspaces of dimension k, 
produces A_k which provides the smallest possible distance from A.
